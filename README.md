# 🌌 Anime Knowledge Arena

The ultimate, gamified trivia platform for anime fans. Test your knowledge, earn XP, and rank up from an Academy Student to a Legendary Sannin!

## 🏆 Key Features
*   **Elite Trivia Database**: Over 60+ creative, high-difficulty questions across Naruto, One Piece, and Attack on Titan.
*   **Anti-Cheat System**: Real-time server-side shuffling of questions and choices. No two quizzes are ever the same!
*   **RPG Progression**: Dynamic leveling logic with real XP requirements and custom ranks.
*   **Global Leaderboard**: Compete against other Otakus to reach the #1 spot.
*   **Achievement Badges**: Earn legendary badges like "Ninja Graduate", "Pirate Recruit", and "Quiz Master".
*   **Modern Gaming UI**: A visually stunning "Night Mode" aesthetic with neon accents and smooth transitions.

## 🛠️ Tech Stack
*   **Backend**: Flask (Python)
*   **Database**: SQLAlchemy (SQLite)
*   **Frontend**: Bootstrap 5, FontAwesome, Custom CSS
*   **Security**: Server-side quiz verification and randomized shuffling.

## 🚀 Deployment (Quick Setup)
1.  **Clone the Repo**: `git clone https://github.com/YOUR_USERNAME/AnimeKnowledgeArena.git`
2.  **Install Dependencies**: `pip install -r requirements.txt`
3.  **Seed the Data**: `python seed.py`
4.  **Run the App**: `python app.py`

Enjoy the challenge, Otaku!
